# Project 1: Reverse

This project implements a simple Unix command-line utility called `reverse`.

The program reads lines from standard input or an input file and prints them in reverse order.

## Features

- Reads input from standard input or a file
- Writes output to standard output or a file
- Reverses the order of input lines
- Detects invalid input and output files
